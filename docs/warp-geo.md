# Warp Geo

Раздел показывает, каким провайдером WARP пользуется узел (Proton/Cloudflare) и как его
исходящий трафик видят внешние сервисы — по конкретному WARP-интерфейсу узла, а не по
сырому IP хоста.

Модуль `warp_geo` выключен по умолчанию — включите в **Настройки → Модули**.

## Статус узла

Выберите узел вверху страницы. Карточка показывает:

- **Провайдер WARP** — `proton` или `cloudflare` (значение `WARP_PROVIDER` из `/root/antizapret/setup`);
  для Proton — заполнен ли WireGuard-ключ отдельно для AntiZapret VPN и для полного VPN (сами ключи
  никогда не показываются и не передаются в панель);
- **WARP для AntiZapret VPN** / **WARP для полного VPN** — режим (`ANTIZAPRET_WARP`/`VPN_WARP`):
  выключен, весь трафик, домены+IP из списков или только домены.

## Гео-проверка

Три проверки — по AntiZapret VPN (`antizapret-*`), по полному VPN (`vpn-*`) и по сырому IP
хоста без WARP. Каждая привязывается к нужному WARP-интерфейсу через `curl --interface`, а не
к маршруту по умолчанию — если интерфейс не поднят (например, провайдер Proton без активного
WARP), проверка честно возвращает ошибку вместо гео сырого IP хоста, которое могло бы ввести
в заблуждение. Все три проверки запускаются автоматически при выборе узла и заново — кнопкой
«Обновить всё» или «Обновить» у конкретного скоупа.

Результат:
- **Гео-детект (Cloudflare)** — страна и colo по `https://1.1.1.1/cdn-cgi/trace`. Это источник
  геолокации, а не активный провайдер трафика — название бейджа намеренно так и звучит, чтобы
  не путать с полем «Провайдер WARP» выше;
- **YouTube** — то же поле `"GL"`, которое использует `warpscout` (см. [README основного
  репозитория](https://github.com/shax0491/AntiZapret-VPN_new#readme), пункт про автоподбор
  эндпоинта Cloudflare WARP);
- **Gemini** — доступность `gemini.google.com` через этот выход (`ok`/`заблокирован`); бейдж
  показывается только если статус не `unknown` (например, сеть недоступна для самой проверки);
- явный бейдж **«видят как Россию»** / **«не Россия»** — истина, если хотя бы один из двух
  признаков (Cloudflare `loc` или YouTube `GL`) равен `RU`.
- если живой тоннель не соответствует сохранённому конфигу (например, конфиг говорит Proton, а
  интерфейс всё ещё держит старый Cloudflare-адрес) — отдельное предупреждение над бейджами:
  результат проверки может относиться к другому провайдеру, чем указано в конфиге.

## Управление WARP

Карточка «Управление WARP» позволяет менять провайдера и Proton-ключи прямо из панели, без
захода на сервер по SSH:

- **Proton / Cloudflare** — переключение `WARP_PROVIDER` в конфиге узла;
- при Proton — по каждому скоупу (AntiZapret VPN / полный VPN) сворачиваемая форма для вставки
  своего WireGuard-конфига Proton (валидируется тем же парсером, что и `setup.sh`; ключи никогда
  не отображаются обратно, только факт «задан»/«не задан»); формы скрыты, если выбран Cloudflare;
- **Применить** — выполняет `up.sh` на узле. Это единственное действие, которое реально поднимает
  новый тоннель — сохранение провайдера/ключей само по себе только пишет конфиг. `up.sh` кратко
  обрывает **все** активные тоннели на этом сервере, не только WARP — предупреждение в интерфейсе
  об этом явно говорит.

### Предпросмотр Cloudflare без переключения

Кнопка **«Проверить Cloudflare без переключения»** отвечает на вопрос «как нас будет видеть
Cloudflare WARP», не трогая текущий рабочий тоннель и не запуская `up.sh`. Технически: на узле
регистрируется одноразовый анонимный Cloudflare WARP-аккаунт, поднимается на отдельном временном
интерфейсе (случайное имя, не пересекается с `warp-antizapret`/`warp-vpn`), через него гоняются те
же гео-проверки (Cloudflare/YouTube/Gemini), и интерфейс сразу же удаляется — независимо от того,
какой провайдер сейчас активен и без изменения `/root/antizapret/setup`. Полезно, чтобы сравнить
Cloudflare и Proton по факту перед тем, как жать «Применить» и обрывать боевые сессии.

## Отличие от AZ-WARP

[AZ-WARP](warper.md) — это точечная маршрутизация конкретных доменов/подсетей через Cloudflare
WARP на узле (отдельный инструмент `warper`). Warp Geo не занимается маршрутизацией — это
только диагностика того, что уже настроено через `setup.sh`/файл `/root/antizapret/setup`.
Если AZ-WARP не используется, его можно выключить в **Настройки → Модули** независимо от
Warp Geo.
